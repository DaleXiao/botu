# botu .impeccable.md — Visual design authority

> This file is the **single source of truth (SoT)** for botu's visual language.
> Any UI change conflicting with this file is automatically rejected; to change the visuals, change this file first.
> Status: **official** (the T-737 W5 draft was reviewed and finalized via SPEC-437 / T-738, 2026-09-22).
> Source: distilled from the existing implementation in css/style.css + index.html + js/app.js, **inventing no new style**; all audit findings (tmp/botu-ui-audit.md) were fixed under SPEC-437 and codified here at their final values.

## 1. Positioning

**A free, registration-free single-purpose tool**: turn any character image into a minimal bot icon. Mode = **Operate** (users come to complete a task); the gallery doubles as Persuade evidence.
The interface stays quiet and steps back; the star is always the user's before→after image pair. Every element must answer: "does it help the user upload, generate, or download?" If not, delete it.
Visual language: **near-black dark default + soft light derivative**, system sans-serif, a single blue accent + a single warm-gold secondary, generous whitespace, thin-line SVG icons. Zero external fonts, zero frameworks, zero build step.

## 2. Typography (hard rules)

- The only font stack: `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Microsoft YaHei", sans-serif`. **External webfonts are forbidden** (free and lightweight is part of the product promise).
- body 15.5px / 1.7, letter-spacing 0.01em; on mobile ≤560px drop to 14.5px.
- Type scale (only these steps are allowed):

| Step | Size/weight | Usage |
|---|---|---|
| tagline | 1.5rem/600 (1.25rem on mobile) | hero headline |
| section | 1.15rem/600 | gallery title |
| card-title | 1.02rem/600 | dropzone title |
| body | 0.93-0.95rem/400 | buttons, secondary copy |
| small | 0.85-0.9rem/400 | hints, quota, footer |
| micro | 0.78-0.82rem/400 | meta, figcaption, pill |

- All numeric readouts (elapsed / file size / quota / gallery index) must use `font-variant-numeric: tabular-nums`.
- Serif faces, decorative italics, and all-caps headings are forbidden.

## 3. Color (hard rules)

**Dark is the primary visual (default dark when no stored preference; follows prefers-color-scheme); light is a derivative of the same language.**

| token | dark | light |
|---|---|---|
| --bg | #161719 | #fafaf8 |
| --panel | #1d1e21 | #fdfdfc |
| --panel2 | #131416 | #f4f4f1 |
| --ink | #c8cace | #3a3d42 |
| --bright | #e8e9ec | #23262a |
| --muted | #85888e | #6f747b |
| --accent | #7fa6e8 | #3d6db5 (AA 4.96 on-bg / 5.00 ink-on-it) |
| --accent2 | #c9a86a | #8a6d35 (AA 4.65/4.70) |
| --accent-ink | #14161a | #fbfbfa |
| --line | #2a2c30 | #e4e4df |
| --err-bg / --err-ink | #2a1c1e / #e08585 | #fbf0ef / #b04a44 |

- The whole site has exactly two colors: --accent (blue = primary interaction color: hover/focus/quota/primary buttons) + --accent2 (warm gold = semantic accents in only two places: quota exhaustion and gallery indices). **A third hue is forbidden.**
- **Contrast hard rule**: when accent is used as text or as a button background, it must reach ≥4.5:1 against the corresponding background (WCAG AA); any token change must be recomputed for both themes (passing dark ≠ passing light; SPEC-437 P1-1 lesson: light accent values once failed at 4.05/4.09/3.81 in three places).
- No gradients, no glassmorphism/backdrop-blur, no glow overlays. Hierarchy comes from lightness: page --bg / card --panel / recessed --panel2.
- ::selection and dropzone hover/dragover tints must follow the accent token: `color-mix(in srgb, var(--accent) N%, transparent)` (selection 28% / dropzone 5%, landed in SPEC-437). **Raw rgba literals are forbidden.**
- Shadows have a single step --shadow (dark `0 1px 3px rgba(0,0,0,.2)` / light `rgba(30,32,36,.05)`), used by .card only.

## 4. Space & shape

- Shell widths come in three steps: page max-width **860** / work card **680** / dropzone and status row **620**, all horizontally centered; main padding `8px 24px 56px`.
- **Four border-radius steps (frozen; adding steps is forbidden)**: container cards **12px** (--radius) / images **10px** / control buttons **8px** / pills **999px**.
- Borders: `1px solid var(--line)`; dashed borders only on the dropzone. Interaction hover = border turns --accent, no layout change, no shifting.
- Card padding 28px (work card 32px 28px); gallery grid gap 16px, 2 columns, 1 column at ≤640px (the in-card before→after pair stays horizontal with nowrap).
- Large-section rhythm: hero top margin 40px; gallery and footer top margin 72px. Prefer emptiness over crowding.
- Images: explicit width/height + loading=lazy are mandatory; displayed width ≤170px, **source assets 340×340 WebP (2× display width, landed in SPEC-437: 8 files totaling ~84KB; the 4.45MB 512px PNGs are retired)**; new gallery assets must use the same spec; 512px+ PNGs are forbidden.

## 5. Motion

- Interaction feedback is limited to **0.15s** transitions on color / border-color / background; primary hover may use `filter: brightness(1.06)`.
- The only continuous animation = the loading spinner (2px ring border rotate **0.9s linear infinite**). Under `prefers-reduced-motion: reduce` it already switches to a non-vestibular signal: the ring color stays unchanged and a `spin-fade` opacity pulse at 1.4s preserves the "loading" state (landed in SPEC-437); **a global 0.01ms kill is forbidden**.
- Loading honesty: show only real elapsed seconds (tabular-nums) + real rotating copy hints; **fake percentages/fake progress bars are forbidden**; if a job has real status, show the real status.
- Forbidden: fly-in entrances, bounce, parallax, skeleton-screen flicker.

## 6. Icons & toggle-control semantics (hard rules frozen in SPEC-436)

- All icons are **inline line-art SVG**: `viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5"` (1.2 for the 56px large placeholder) with round caps/joins; decorative icons are aria-hidden; color is always currentColor, never hardcoded. **Emoji and text-character icons are forbidden** (☾/☀ are retired; zero production hits is an acceptance criterion).
- **Toggle-style controls show the "target state" icon**: dark shows a sun (click to go light) / light shows a moon (click to go dark); the icon semantics must match aria-label/title (i18n keys themeAriaToLight/themeAriaToDark). Reference source: icon-forge App.tsx:182/188 (paths verbatim).
- themeBtn static initial = sun SVG (consistent with default dark), eliminating the post-JS-load flip; on the JS side renderThemeBtn swaps in the SUN_SVG/MOON_SVG constants via innerHTML (app.js:42-43).
- The brand mark (circle r9.25 + double rounded-rect eyes) is reused in three places — brand / dropzone / result placeholder — and is the product signature; **private single-place edits are forbidden**.

## 7. Anti-AI-slop checklist (violation = rejected)

1. ❌ Purple-blue gradients / "AI purple" palettes
2. ❌ Glassmorphism / backdrop-blur abuse
3. ❌ Self-congratulatory copy — botu copy states facts only (free / no registration / ~3-4 minutes / supported formats)
4. ❌ Emoji as icons
5. ❌ Meaningless badges ("Beta", "Powered by" are all deleted)
6. ❌ Fake progress percentages
7. ❌ Serif fonts / decorative italic headings
8. ❌ New hues, new radius steps, new shadow steps

## 8. Component baselines

- **pill** (top-bar round buttons): transparent background + 1px --line border + --muted text; hover turns everything --accent; focus-visible 2px accent outline + 2px offset; **mobile ≤560px min-height/min-width 44px (inline-flex centered, landed in SPEC-437), desktop keeps the compact look**.
- **btn**: transparent background + --line border + --ink text, radius 8, padding 9px 22px; hover turns accent; disabled opacity .45 + pointer-events none.
- **btn.primary**: --accent background + --accent-ink text + weight 600; hover only brightness(1.06).
- **card**: --panel background + --line border + --shadow + radius 12, text-align center.
- **dropzone**: card variant, dashed border, 52px 28px padding; hover/dragover = accent border + accent 5% background (color-mix); role=button + tabindex=0 + Enter/Space triggers fileInput.
- **errbox**: --err-bg/--err-ink + role=alert + word-break; **quota row**: --accent text + role=status, turns --accent2 when exhausted; both are hidden by default, fail-open.
- **slot/result box**: inline SVG placeholder colored by theme currentColor; **no state may ever show an <img> with an empty src**.
- **gallery card**: before→after forced horizontal (nowrap); idx uses --accent2 + tabular-nums; caption centered at the micro step; img 340×340 WebP + width/height attributes + lazy.
- **topbar**: brand left (mark 22px + wordmark 1.05rem/600), pill group right (theme+lang, gap 8px).
- **footer**: border-top --line, three layers = SEO copy (small) / attribution (footnote, --ink) / copyright (micro).

## 9. Behavior & i18n rules

- Theme: an inline head script pre-applies `data-theme` (localStorage `botu-theme` → prefers-color-scheme → default dark), zero flash; toggling must write back to localStorage.
- Language: driven by data-i18n keys; setLang must keep `documentElement.lang` in sync (zh-CN/en, i18n.js:123); every new key must land in both languages.
- Asset versioning: **any css/js/image content change must bump `?v=`** (the zone browser_cache_ttl overrides _headers, measured max-age=14400; currently **?v=437**; the ≤4h regression window from SPEC-436's lagging content version was closed by the SPEC-437 bump).
- quota/status read failures fail open and never block generation; errors go only to errBox + console; alert/popup dialogs are forbidden.
